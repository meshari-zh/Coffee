# مشروع موقع المقهى (Coffee Shop Project)

مشروع بسيط لتصميم موقع إلكتروني لمقهى، تم إنشاؤه كواجب دراسي باستخدام تقنيات الويب الأساسية.

## التقنيات المستخدمة
* **HTML5** - بناء هيكلية الصفحات
* **CSS3** - التنسيق والألوان
* **JavaScript** - التفاعلية الأساسية

## ملفات المشروع
* `index.html` - الصفحة الرئيسية
* `about.html` - صفحة عن المقهى
* `menu.html` - قائمة الطعام والمشروبات
* `contact.html` - صفحة التواصل
* `css/` - مجلد التنسيقات
* `js/` - مجلد السكريبتات
* `images/` - مجلد الصور
